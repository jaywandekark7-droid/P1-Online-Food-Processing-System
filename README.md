# P1 – Online Food Processing System Using Queue

Second-year B.Tech AIML mini project.

## Objective
A simple food-order processing system using a Queue and the FIFO (First In, First Out) principle.

## Technologies
- Python
- collections.deque
- Google Colab / any Python environment

## Features
1. Place a food order
2. View pending orders
3. Process the next order
4. View completed orders
5. Exit

## Run
```bash
python online_food_processing.py
```

## Data Structure
Queue using `deque`.

Adding and processing an order are O(1); displaying all pending orders is O(n).
